# Security Policy

## Reporting Issues

This is a private repository. If you discover a security concern, document it privately and address it before any public exposure.

## Sensitive Data

- Never commit API keys, tokens, or passwords
- Use `.env` files for all secrets (gitignored)
- ElevenLabs, OpenAI, Discord, and Bambu credentials must stay out of source control
- GitHub token and OpenClaw config must stay out of source control
