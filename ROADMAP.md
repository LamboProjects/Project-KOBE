# Roadmap

## Phase 1 — Core Voice MVP
**Goal:** KOBE can hear, think, and speak reliably on the PC.

- [ ] Wake word detection ("Hey KOBE", "OK KOBE")
- [ ] Local STT with faster-whisper (GPU-accelerated)
- [ ] High-quality TTS output (ElevenLabs)
- [ ] Barge-in / interruption support
- [ ] Software mute toggle
- [ ] Physical mute button scaffold
- [ ] Basic voice command routing
- [ ] App launching by voice

**Success:** KOBE responds quickly and consistently. App launching works reliably. Already useful.

---

## Phase 2 — HUD MVP
**Goal:** Give KOBE persistent visual presence on the second monitor.

- [ ] Fullscreen always-on HUD
- [ ] KOBE state indicator (muted / idle / listening / thinking / speaking)
- [ ] Live voice transcript panel
- [ ] Response display panel
- [ ] Basic system status widgets
- [ ] Visual theme established (dark, cyan, futuristic)

**Success:** KOBE feels like a live desktop system, not just a voice utility.

---

## Phase 3 — Productivity & Printer Integration
**Goal:** Make KOBE materially useful in daily workflows.

- [ ] Bambu Lab P1S dashboard on HUD
- [ ] Voice queries for print state
- [ ] Print completed / failed alerts via voice + Discord
- [ ] Pause / resume / cancel print with confirmation
- [ ] App automation improvements
- [ ] Spotify control (play, pause, next, volume, playlist)
- [ ] Steam game launch by voice
- [ ] Better desktop action support

**Success:** KOBE is part of actual daily printing and desktop workflow.

---

## Phase 4 — Screen Vision & Context Awareness
**Goal:** Increase usefulness during active work.

- [ ] On-demand screen inspection
- [ ] Active app context detection
- [ ] Coding help in VS Code context
- [ ] Print settings reading in Bambu Studio
- [ ] CAD troubleshooting assistance

**Success:** KOBE can interpret what is on screen in a practical way.

---

## Phase 5 — Gesture Control
**Goal:** Add a second natural interaction channel.

- [ ] Webcam integration
- [ ] MediaPipe hand tracking
- [ ] Swipe left / right
- [ ] Point / select
- [ ] Confirm / dismiss gestures
- [ ] HUD panel navigation by gesture

**Success:** Gesture features are genuinely usable and not frustrating.

---

## Phase 6 — Premium Polish
**Goal:** Make the system feel cohesive and intentional.

- [ ] TTS voice tuning and persona refinement
- [ ] Better HUD animations and transitions
- [ ] Smoother command handoff behavior
- [ ] Improved Discord integration
- [ ] Smart home hooks (smart plug → lights)
- [ ] Multi-profile architecture prep (Jasmine)

**Success:** KOBE feels polished, not experimental.

---

## Phase 7 — Holographic Fan Integration
**Goal:** Add spectacle and ambient visual presence.

- [ ] Holographic fan media pipeline
- [ ] KOBE logo animation
- [ ] Music-reactive visuals
- [ ] Printer status visuals
